# Banco de dados local

O aplicativo grava tudo nesta pasta:

| Arquivo / pasta | Conteúdo |
|-----------------|----------|
| `inaja.sqlite` | Banco SQLite (tabelas, usuários, solicitações, tarefas…) |
| `uploads/` | Anexos enviados nas solicitações |

Não é necessário Supabase nem internet para o banco funcionar.
O arquivo `inaja.sqlite` é criado automaticamente na primeira execução.
